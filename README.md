# TeamTasks

A command-line task tracker for small teams, written in Python 3 with no outside dependencies.

## Run it
    python teamtasks.py demo
    python teamtasks.py list
    python teamtasks.py summary

## Test it
    python -m unittest -v

## Commands
`add`, `list`, `done`, `summary`, `demo`. Run `python teamtasks.py --help` for details.
